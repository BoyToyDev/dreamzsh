# 🌙 DreamZSH

**Минималистичная ZSH конфигурация с интерактивным конструктором тем и менеджером**

DreamZSH — это модульная альтернатива тяжеловесным фреймворкам вроде Oh My Zsh.

## ✨ Особенности

- 🎨 **Интерактивный конструктор тем** — настройка цвета и символов без редактирования конфигов
- 🔌 **Модульные плагины** — подключайте только то, что нужно
- 🔤 **Nerd Fonts** — установка шрифтов с иконками
- 🚀 **Менеджер** — управление всеми компонентами через удобное меню
- 🌍 **Русский и English** — интерфейс установщика на двух языках

## 📦 Установка

```bash
git clone https://github.com/BoyToyDev/dreamzsh.git ~/dreamzsh
cd ~/dreamzsh
chmod +x install.sh
./install.sh
