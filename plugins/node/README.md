# node

Aliases for Node.js package managers: npm, yarn, pnpm, bun, and nvm.

## What it does

Short aliases for all major JS package managers. Each set only activates if the tool is installed.

## npm aliases

| Alias | Command |
|-------|---------|
| `ni` | `npm install` |
| `nid` | `npm install --save-dev` |
| `nr` | `npm run` |
| `nrd` | `npm run dev` |
| `nrb` | `npm run build` |
| `nrt` | `npm run test` |
| `nci` | `npm ci` |

## yarn aliases

| Alias | Command |
|-------|---------|
| `y` | `yarn` |
| `ya` | `yarn add` |
| `yad` | `yarn add --dev` |

## pnpm aliases

| Alias | Command |
|-------|---------|
| `pn` | `pnpm` |
| `pni` | `pnpm install` |

## bun aliases

| Alias | Command |
|-------|---------|
| `b` | `bun` |
| `bi` | `bun install` |

## Functions

| Function | Description |
|----------|-------------|
| `npm-clean` | Remove node_modules and all lockfiles |
| `npm-global-list` | List globally installed packages |
