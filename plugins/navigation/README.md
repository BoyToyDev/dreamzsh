# navigation

Shortcuts and helpers for filesystem navigation.

## Features

- enables `AUTO_CD`
- enables directory stack support
- adds shortcuts for moving around faster

## Included aliases

- `..`
- `...`
- `....`
- `.....`
- `-` → `cd -`
- `md` → `mkdir -p`
- `rd` → `rmdir`

## Included functions

- `cdb` — go back to previous directory
- `mkcd <dir>` — create directory and enter it
- `up [n]` — go up by `n` directory levels
