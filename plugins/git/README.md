# git

Basic Git aliases and helper functions for everyday work.

## Included aliases

- `g` → `git`
- `gs` → `git status`
- `gss` → `git status --short`
- `ga` → `git add`
- `gaa` → `git add --all`
- `gc` → `git commit`
- `gcm` → `git commit -m`
- `gca` → `git commit --amend`
- `gco` → `git checkout`
- `gcb` → `git checkout -b`
- `gb` → `git branch`
- `gbd` → `git branch -d`
- `gd` → `git diff`
- `gds` → `git diff --staged`
- `gf` → `git fetch`
- `gl` → `git pull`
- `gp` → `git push`
- `glog` → `git log --oneline --graph --decorate --all`

## Included functions

- `groot` — print Git repository root
- `gclean-merged` — remove merged local branches except `main` and `master`
